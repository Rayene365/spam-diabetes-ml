# Machine Learning Classification Project

## Objective

Implement a shared machine learning workflow and apply it to two
binary classification datasets:

- Spambase: classify emails as spam or non-spam.
- Diabetes Health Indicators: predict the binary diabetes indicator.

The project will compare classification methods, implement feature
selection, and evaluate performance using appropriate metrics.

## Planned organization

- `ml_workflow.py`: shared data loading, preprocessing, training,
  and evaluation functions.
- `spambase.ipynb`: experiments and discussion for Spambase.
- `diabetes.ipynb`: experiments and discussion for Diabetes.
- `test_ml_workflow.py`: unit tests.
- `data/`: datasets and their documentation.

## Environment setup

Create and activate a Python virtual environment, then install:

    python -m pip install -r requirements.txt
