# Datasets

## Spambase

spambase/spambase.data contains 4,601 rows and 57 features.
The file has no header. The last column is the label: 1 for spam
and 0 for non-spam.

Feature names are listed in spambase/spambase.names.
[Source: UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/94/spambase)

## Diabetes Health Indicators

diabetes/diabetes_binary_health_indicators_BRFSS2015.csv contains
253,680 rows and 21 features. The target column is Diabetes_binary.

Class 0 has 218,334 rows. Class 1 has 35,346 rows (13.9%).

[Dataset source on Kaggle](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)
